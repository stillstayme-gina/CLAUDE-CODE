# 서울·근교 주말 아이 동반 루트 (초안)

> 장소·운영 정보는 방문 전 공식 사이트 확인 필요. 식당의 네이버 평점·유아의자는 **아직 검증 안 됨** (`data/restaurants.json` 참고).

## 3세 이하
| 루트 | 일정 | 식사 후보 |
|---|---|---|
| 잠실 실내 코스 | 롯데월드 아쿠아리움 → 점심 → 석촌호수 유모차 산책 | 롯데월드몰 식당가 |
| 마곡 식물원 코스 | 서울식물원 온실 → 점심 → 호수원 산책 | 마곡나루역 주변 |
| 성수 산책 코스 | 서울숲(꽃사슴) → 점심 → 낮잠 시간 귀가 | 성수동 상권 |

## 3~6세
| 루트 | 일정 | 식사 후보 |
|---|---|---|
| 광진 하루 코스 | 서울상상나라(예약) → 점심 → 어린이대공원 동물원·놀이터 | 건대 스타시티·롯데백화점 |
| 과천 코스 | 서울대공원 동물원 → 국립현대미술관 어린이미술관 | 공원·미술관 내 식당 (확인 필요) |
| 용산 코스 | 국립중앙박물관 어린이박물관(예약) → 거울못 산책 | 용산 아이파크몰 |
| 근교(용인) | 경기도어린이박물관(예약) | 박물관 주변 (확인 필요) |

| 비행기 코스 | 국립항공박물관 → 김포공항 전망 | 롯데몰 김포공항점 |

| 공룡 코스 | 서대문자연사박물관 → 안산자락길 | 주변 (확인 필요) |

## 식당 검증 기준
1. 네이버 지도 별점 4.0 이상
2. 플레이스 '편의시설'에 유아의자 표시 또는 리뷰에서 확인
3. 별점이 표시되지 않는 곳은 방문자 리뷰 수 + "아이와 가기 좋아요" 키워드로 대체 판단
