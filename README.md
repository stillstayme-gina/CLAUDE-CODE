# 발밑의 시간

한반도 지질을 **지금 내가 서 있는 자리**에서 시작해 읽는 웹 시안.
일반인(특히 산에 다니는 성인)이 1차 타깃, 중·고등학생이 2차 타깃입니다.

> 한반도는 작지만, 지구 역사의 절반이 들어 있다.

## 왜 이렇게 만들었나

기존 지질 소개 사이트는 `지질도 / 산 / 지질공원 / 트레킹 / 행사`를 탭으로 나열합니다.
그러면 백과사전이 되고, 방문자는 "나한테 왜 필요한데?"라는 질문에 답을 못 받은 채 메뉴 앞에 섭니다.

이 시안은 콘텐츠를 **하나의 축(지질 시간)** 위에 배치하고,
**개인화된 진입점(내 발밑)** 으로 사람을 끌어들인 뒤,
**현장(가서 볼 것)** 으로 내보내는 구조를 씁니다.

## 구성

홈은 히어로 + 발밑 조회 + 카드 여섯 장만 둡니다. 나머지는 해시 라우터로 페이지가 갈립니다.

| 페이지 | 내용 |
|---|---|
| `#/` 홈 | 히어로, 발밑 빠른 조회, 카드 6장 |
| `#/footprint` 내 발밑 | 시·군·구 251곳 또는 위치 권한 → 지질구·나이·형성 과정·가 볼 곳·가까운 지질명소 3곳·공유 문구 복사 |
| `#/map` 지질도 | 실제 행정경계 위의 지질도. 12단계 타임 슬라이더, 지질명소·활성단층 레이어, 지진 |
| `#/mountains` 산 | 주요 산 160곳 도감 — 이름·지역·암석 검색, 지질구 필터, 가까운 순 정렬. 그중 7곳은 4컷 탄생 시퀀스 |
| `#/geoparks` 지질공원 | 12곳·명소 46개. 명소별 "왜 재미있나"와 "이것만은 보고 오세요", 현장 체크인과 도감 |
| `#/trails` 지질 트레일 | 코스 14개. 고도 프로파일 **아래**에 지질 단면을 겹쳐, 어느 지점에서 시대가 바뀌는지 |
| `#/stories` 이야기 | 동해 열개 / 경상분지 공룡 / 한탄강 용암대지 |
| `#/rock` 돌 이름 | **사진을 올리면 Claude가 암종을 추정**. 사진이 없으면 질문 2~3개로 좁히는 검색표 |
| `#/sources` 자료 출처 | 기관별로 무엇을 가져왔고 이 시안에서 어떻게 가공했는지 |
| `#/visits` 방문 지도 | 동의한 방문자의 시·도·지질구 합계. 좌표·시각·식별자는 저장하지 않음 |
| `#/quiz` 퀴즈 | 널리 퍼진 오해 10문항 O·X |
| `#/about` 만든 사람 | 소개, 즐기는 법, 데이터의 한계와 출처 |

## 지도

바탕은 **실제 행정경계**입니다 (통계청 2013, `southkorea-maps`). 세 겹으로 그립니다.

1. 시·도 경계에서 만든 육지 윤곽을 SVG `clipPath`로 씁니다 — 지질구가 해안선을 넘지 않습니다.
2. 시·군·구 249곳을 그 지역의 지질구 색으로 칠해 밑판을 깝니다 — 지질구 폴리곤이 해안선까지 닿지 않는
   가장자리와 섬(미포함 5.0%)을 메웁니다. 이 밑판까지 더하면 미포함이 0.23%로 떨어집니다.
3. 그 위에 지질구 폴리곤을 그려 육괴·옥천대 띠 구조가 보이게 합니다.
   꼭짓점이 적어 각져 보이던 경계는 Catmull-Rom 곡선으로 부드럽게 그립니다(그리기 전용이고,
   판정은 원래 폴리곤을 씁니다). 지질구 이름과 나이는 지도 위에 직접 올려, 범례를 오가지 않아도
   무슨 색인지 바로 읽히게 했습니다. 라벨 자리는 폴리곤 안이면서 실제 육지인 점들의 평균으로
   잡아 바다 위에 놓이지 않습니다.

산·지질명소·조회한 위치에서 **지도로 이동하면 그 지점을 확대하고 이름을 붙입니다.** 확대할 때
선 굵기·마커·글자가 같이 커지지 않도록, 현재 배율을 `--mk` 커스텀 속성으로 내려보내 모든 마크가
그만큼 되돌아갑니다. 울릉·독도 삽도는 지도 좌표에 놓여 있어 확대 중에는 숨깁니다.

신안 먼바다 섬(가거도·흑산도 등)은 지도 폭의 27%를 차지해 한반도를 작게 만들기 때문에
바탕지도에서 생략했습니다. 그 결과 지도 폭이 402 → 304 단위로 줄어 한반도가 32% 크게 보입니다.

지도 타일 서버를 쓰지 않으므로 오프라인·단일 파일로도 동작합니다.

## 지질 트레일 단면도

등산 앱은 거리와 고도를 보여줍니다. 여기서는 그 프로파일 **아래**를 같이 그립니다.

- 지표선 위는 고도, 아래는 지질 단면. 커서를 올리면 그 지점에서 밟는 암석과 나이가 나옵니다.
- 암체는 위에서 아래 순서로 정의하고, `base`가 상수면 수평 경계, `[[km,m],...]`면 기울어진 경계입니다.
- 설악산은 900m에서 19억 년 편마암과 8,700만 년 화강암이 갈립니다. 지표선이 1.75km 지점에서
  그 경계를 넘는 것이 그대로 보입니다.
- 지하 구조는 모식이며, 목적은 **지표에서 실제로 밟게 되는 순서**를 보여주는 것입니다.
  단면도 캡션과 페이지 하단에 명시했습니다.

차트는 `dataviz` 규약을 따릅니다 — 코스별 실제 색 조합을 팔레트 검증기로 돌려
라이트·다크 모두 통과시켰고, 표 보기·직접 라벨·호버 십자선을 갖췄습니다.

## 시대색 팔레트

색은 나이입니다. 시대색은 CSS 토큰(`--e-*`)이 원본이고 JS는 그 값을 읽으므로
라이트·다크가 각각 따로 검증됩니다.

기존 값은 채도가 낮아 차트 팔레트 검사에서 탈락했습니다(선캄브리아↔고생대 전기 CVD ΔE 1.8,
고진기↔제4기는 정상 시야에서도 ΔE 4.4). 시대 구분의 의미는 유지한 채 채도와 간격을 다시 잡았고,
한 차트에 실제로 함께 쓰이는 조합은 전부 통과합니다. 지도처럼 8색이 한 번에 나오는 화면은
범례와 개별 라벨이 함께 있어야 한다는 뜻이며, 그렇게 구성돼 있습니다.

## 자료 출처 표시

지질 정보는 출처가 곧 신뢰도입니다. 기관 여덟 곳을 `assets/js/14-data-sources.js`에 정리하고,
각 항목마다 **여기서 가져온 것**과 **이 시안에서 어떻게 가공했는지**를 함께 적었습니다.
페이지마다 하단에 그 페이지가 쓴 자료가 칩으로 붙고, 누르면 원본으로 갑니다.

## 위치 자동 사용

처음 들어오면 한 번 물어보고, 허용하면 그 뒤로는 들어오자마자 발밑이 채워집니다.
설정은 `localStorage`에만 남고 위치는 브라우저 밖으로 나가지 않습니다(방문 지도에
직접 남기는 경우는 예외이며, 그때도 시·도와 지질구만 저장합니다).
내 발밑 페이지의 스위치로 언제든 끌 수 있습니다.

## 산 160곳

이름·지역·암석으로 검색하고 지질구로 거릅니다. 위치 권한을 켜면 가까운 순으로 정렬됩니다.
각 산의 **지질구와 암석은 정상부 좌표를 지질구 경계에 넣어 자동으로 붙입니다** — 산마다 손으로
쓰지 않았다는 뜻이고, 그래서 경계에 걸친 산은 실제와 다를 수 있습니다.

좌표는 **실제 시·도 경계 폴리곤으로 검증**했습니다. 160곳 중 150곳이 표기한 시·도와 정확히
일치하고, 나머지 10곳은 행정 경계에 걸쳐 있거나(북한산·무등산·팔공산 등) 단순화된 폴리곤
밖의 섬입니다.

## 런타임 기능 (발행본 전용)

- `sample` — 암석 사진을 Claude에게 보내 암종을 추정합니다. 후보 최대 3개, 각각 사진에서 보이는
  근거와 현장 확인 방법. 뷰어가 Claude 사용을 허용해야 하고, 쓸 수 없으면 질문 방식으로 자동 전환됩니다.
- `db` — 방문 지도의 집계 저장소.

저장소 버전(`index.html`)은 두 기능 없이도 그대로 동작합니다.

## 방문 지도 — 무엇을 저장하지 않는가

- **저장**: 시·도 이름, 지질구 이름, 날짜(일 단위)
- **저장하지 않음**: 정확한 좌표, 시·군·구, 시각, 기기 정보, 식별자
- 개별 기록은 표시하지 않고 합계로만 보여줍니다
- 버튼을 직접 누른 경우에만 기록됩니다. 위치 조회만으로는 저장되지 않습니다

한국에서 개인의 정확한 위치정보를 모아 보관하는 일은 위치정보법과 개인정보보호법의 규율을
받습니다. 시·도 단위 합계만 남긴 이유이고, 더 자세한 분석이 필요하면 이용약관·동의 절차·
보관 기간을 갖춘 뒤에 설계해야 합니다.

## 체크인

지질명소 46곳. 위치 권한을 켜고 3km 안에 있으면 **현장 체크인**, 밖이면 거리 안내 후 **방문 기록**만
남길 수 있습니다. 기록은 `localStorage`에만 저장되고 어디로도 전송되지 않습니다.
지질공원 하나를 다 채우면 완주 배지가 붙습니다.

## 콘텐츠 규칙

1. 모든 구간은 **질문**으로 시작한다. 설명으로 시작하지 않는다.
2. 전문용어는 쓴다. 단, 첫 등장에 한 줄 풀이를 붙인다.
3. 숫자는 비유와 함께 쓴다.
4. 모든 온라인 콘텐츠는 **현장 CTA**로 끝난다.

```

assets/js/0*-data-*.js       데이터 (시대 · 지질구 · 바탕지도 · 지질공원 · 암석 · 산 · 이야기 · 퀴즈)
assets/js/10-geo.js          투영 · 점-다각형 판정 · 지질구 조회
assets/js/11-store.js        localStorage · 거리 계산
assets/js/20-map.js          SVG 지질도 + 타임 슬라이더
assets/js/30-footprint.js    내 발밑
assets/js/35-geoparks.js     지질공원 · 체크인 · 도감
assets/js/40~50-*.js         산 · 이야기 · 퀴즈
assets/js/45-rockid.js       돌 이름 검색표
assets/js/90-app.js          부팅
assets/js/92-router.js       해시 라우터
tools/make-basemap.mjs       행정경계 원본 → 바탕지도 + 시군구 좌표 생성
tools/build.mjs              index.html / dist/index.html 생성
```

빌드 도구·의존성 없음. 순수 HTML/CSS/JS.

```sh
node tools/build.mjs        # index.html 과 dist/index.html 생성
python3 -m http.server 8777 # http://localhost:8777
```

`dist/index.html` 은 CSS·JS를 한 파일에 인라인한 배포본입니다.

## 데이터의 한계 — 반드시 읽을 것

- **행정경계는 실제, 지질구는 개략입니다.** 바탕의 행정경계는 통계청 2013 자료를 단순화한
  실제 경계이지만, 그 위에 올린 지질구는 1:25만급 지질도를 크게 단순화한 폴리곤 15개입니다.
  251개 시·군·구 좌표가 모두 합리적인 지질구로 판정되는 것은 확인했지만,
  그것이 지질 경계의 정확도를 뜻하지는 않습니다.
- **지질공원 인증 연도**는 확실한 네 곳(제주 2010, 청송 2017, 무등산권 2018, 한탄강 2020)만
  표기했습니다. 전체 목록과 최신 인증 현황은 국가지질공원 누리집에서 확인이 필요합니다.
- **트레일의 고도와 지층 경계는 개략값입니다.** 실제 측량 자료가 아니라 공개 정보를 바탕으로
  구성했고, 지하 구조는 모식입니다. 등산 계획에는 국립공원공단과 지자체의 최신 정보를 쓰세요.
- **암석 검색표는 간이 판별입니다.** 실제 동정에는 현미경과 화학 분석이 필요하고,
  자연에는 중간 성질의 암석이 훨씬 많습니다.
- **연대는 대푯값입니다.** 하나의 육괴 안에도 수억 년 차이가 나는 암석이 함께 있습니다.
- **연대·지층 서술은 전공자 검수가 필요합니다.** 특히 설악산 화강암 연대,
  옥천대 퇴적 시기, 한탄강 용암대지 연대, 임진강대 충돌설.
- 지질도·지질공원·지진 원자료를 실제로 연동하려면 KIGAM 지질정보시스템,
  국가지질공원 누리집, 기상청 지진화산 정보의 **공공누리 유형 확인**이 선행되어야 합니다.
